# Unlocking-Societal-Trends-in-Aadhaar-Enrolment-and-Updates-2025-
Interactive Power BI dashboard analyzing Aadhaar enrollment, demographic, and biometric data. Features KPI tracking, regional insights, demographic trends, and biometric performance analysis using Power BI, DAX, and Power Query.

## Overview
This Power BI dashboard provides a comprehensive analysis of Aadhaar enrolment and update data, uncovering trends across enrolment activities, demographic distributions, and biometric registrations. The project transforms large-scale public data into actionable insights through interactive visualizations and KPI-driven reporting.

## Key Areas of Analysis

### Enrolment Analysis
- Total Aadhaar enrolments and updates
- State-wise and regional enrolment performance
- Enrolment trends over time
- Comparison of enrolment and update activities
- Identification of high-performing and low-performing regions

### Demographic Analysis
- Gender-wise enrolment distribution
- Age-group segmentation
- Regional demographic comparisons
- Population participation trends
- Analysis of societal patterns across demographic categories

### Biometric Analysis
- Biometric enrolment statistics
- Fingerprint and iris registration trends
- Biometric update patterns
- Regional biometric performance analysis
- Comparative analysis across demographic groups
